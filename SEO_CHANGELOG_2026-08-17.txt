8. GOOGLE SEARCH CONSOLE — YOUR STEPS
============================================================
1. Go to https://search.google.com/search-console, add coinbids.eu as a
   property (Domain property, not URL-prefix, is usually simplest if your
   DNS provider is accessible for a TXT record).
2. Verify ownership. The simplest method for a domain you don't already
   have GSC-linked: add a TXT record at your DNS provider — Search Console
   gives you the exact value to add when you start this step. No file or
   meta tag needs to be added to the site for this method, so nothing in
   this delivery needs to change for it.
   (Alternative: HTML-file verification — if you'd rather do that, tell me
   and I'll add the specific verification file Google gives you; I have not
   pre-added one since I don't have a real verification token to put in it.)
3. Once verified, submit sitemap.xml: Search Console → Sitemaps → enter
   "sitemap.xml" → Submit.
4. Use URL Inspection on https://coinbids.eu/ → Request Indexing.
5. Repeat URL Inspection + Request Indexing for the 4 feature pages.
6. Do NOT request indexing for /app — it's intentionally excluded (§ the
   robots.txt Disallow) since it's a login gate, not content.
7. Check back in Search Console's Coverage/Indexing report after a few days
   to confirm pages were actually indexed, not just submitted.
